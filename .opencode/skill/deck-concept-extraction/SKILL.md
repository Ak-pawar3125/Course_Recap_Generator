---
name: deck-concept-extraction
description: Extract key concepts from a slide deck into a consistent structured summary
---

# Output format (always)

1. Title and one-sentence deck purpose
2. 5-8 key concepts: **Concept**: 1-2 line explanation (slide numbers)
3. Per-topic sections with 3-5 bullets each
4. Relationships: list "A -> B (reason)" pairs (feeds the diagram)
5. Glossary of terms

# Rules

- Only use content present in the slides. Never invent.
- Cite slide numbers for every key concept.
